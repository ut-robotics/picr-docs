=== Routing differential pairs

. Make sure that differential pair net names end with `+` and `-` or `P` and `N`.
+
image::kicad_differential_pair_net_names.png[]
+
. In PCB Editor open File -> Board Setup and create a net class for differential pair nets.
Specify differential pair (DP) width and gap from PCB manufacturer's calculator or from some other calculator.
+
image::kicad_differential_pair_net_class.png[]
+
Also make sure that minimum track width constraint is smaller than differential pair track width.
+
image::kicad_differential_pair_minimum_track_width_constraint.png[]
+
. Position components so that the differential pair traces can be as straight as possible.
If there are other components or traces close to the differential pair traces,
try to move them further away.
+
image::kicad_differential_pair_routing_component_positioning.png[]
+
. Start routing by clicking _Route Differential Pairs_ button or by pressing `6` on keyboard. +
KiCad documentation: https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html#routing-differential-pairs
+
image::kicad_differential_pair_routing_button.png[]
+
To reduce impedance discontinuities and intra-pair skew:
try to avoid bends,
avoid using vias if possible or reduce the amount of vias
and keep traces as symmetrical as possible.
+
Some manual adjustments might be needed, which can be done by simply moving the tracks
or rerouting segments of the tracks with _Route Single Track_ (hotkey `X`) tool.
+
image::kicad_differential_pair_routed_tracks.png[]
+
When connecting tracks to ESD protection component, the tracks should go straight to the ESD protection component
(like on the image above) to avoid ESD propagating between narrow gaps between tracks.
+
image::kicad_differential_pair_esd_protection_incorrect_connection.png[]
+
Stubs should be avoided in tracks as these will reduce ESD protection effectiveness
and also cause signal reflections in general.
+
image::kicad_differential_pair_stubs.png[]

=== Gerbers and Drill Jobs

. Select `PCB: Export Gerbers` when adding a new Job.
+
image::kicad_add_gerbers_job.png[]
+
. Use the following Gerber Job Settings.
+
image::kicad_gerber_job_settings.png[]
+
. Add another Job and select `PCB: Export Drill Data`.
+
image::kicad_add_drill_data_job.png[]
+
. Use the following Drill Data Job Settings.
+
image::kicad_drill_data_job_settings.png[]
+
. Open destination folder settings.
+
image::kicad_jobset_destination_folder_settings_open.png[]
+
. Change `Destination path` to `${KIPRJMOD}`.
+
image::kicad_jobset_destination_folder_settings_destination_path.png[]
+
. Press `Save Jobset`.
+
image::kicad_jobset_save.png[]
+
. Press `Generate`.
+
image::kicad_jobset_folder_generate.png[]
+
. Commit Jobset (`\*.kicad_jobset`) and Gerber (`GerberX2/*.gbr`) files to the repository.
+
. If the Gerber files need to be updated open the Jobset and press Generate.
